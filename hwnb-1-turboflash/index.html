HWNB-1-turboflash

周期性固定输出的 decoder-only Transformer · 纯 NumPy · 零依赖

无论输入什么，都从同一句话开始、按同一份文档持续输出，直到达到字节上限（默认 15 MB）。

下载 model.bin README content.txt

规格

模型文件270,284 bytes（263.9 KB）
参数243,200
结构2 层 / 4 头 / d_model 64 / d_ff 160 / 窗口 64
量化int8 行量化 + float32 RMSNorm gamma + SHA-256 校验
内容长度2,001 字（635 个不重复字符）
训练2,600 步 / 227 s / 最终 loss 9.6e-4
自测逐 token 生成 4,034 个（两整轮 + 32），min logit margin 2.27
15 MB 输出约 7.1 s（生成校验 + 周期重复）

原理

周期位置嵌入：相位 = 文档下标 mod C，另有 SEP / 其他两个相位。注意力用滑窗 （最近 64 个答案 token），答案行永远看不到用户 token。因为相位周期性，模型在窗口内 看不到「这是第几遍」，同一位相永远预测同一个 token，于是可以无限循环。

运行时并不盲信这个假设：先逐 token 真实生成两整轮 + 32 个 token 并全部断言， 确认后再按字节上限重复已验证的周期。

使用

# 下载 model.bin 到本目录后
cd core
python hwnb.py --model ../hwnb-1-turboflash/model.bin --once
python hwnb.py --model ../hwnb-1-turboflash/model.bin --max-bytes 15728640 > out.txt
python hwnb.py --model ../hwnb-1-turboflash/model.bin --selftest
任意 prompt 生成的 token 序列逐 token 相同；这是掩码与相位设计的结果， 自测会同时验证这一点。
