# π-1-Pro

输入任意内容后，计算圆周率并持续输出，**不限制大小**，不打断就一直输出。

这个模型故意**不是神经网络**：Transformer 无法无限生成 π 的数字而不漂移成
胡编乱造，而需求要的是「算多快就多快、数字必须正确」，所以每一位都是真算出来的。

- 运行时：`../core/pi1pro.py`
- 依赖：无（若装了 `gmpy2` 自动启用，快约 20 倍）
- 输出：`3.` 开头，之后无限小数位，直到你按 Ctrl-C 或关闭管道

## 算法

| 角色 | 算法 |
|---|---|
| 主引擎 | Chudnovsky 级数 + 二分拆分 + 整数平方根 |
| 交叉校验 | Gibbons spigot（独立算法、不共享常数） |
| 增长策略 | 按块增长：算到 N 位 → 只输出新增切片 → 块倍增 |

每次重算都会断言「新前缀以旧前缀开头」，所以单个错误数字不可能悄悄溜出去。
启动时先用两种算法对前 1000 位对拍（`--verify` 可查更多位）。

## 用法

```bash
cd core

python pi1pro.py                        # 无限输出（Ctrl-C 停止）
python pi1pro.py --first-block 100000   # 更大的首块，首屏稍慢但后程更快
python pi1pro.py --out pi.txt           # 写文件直到 Ctrl-C
python pi1pro.py --max-digits 1000000   # 算到 100 万位就停
python pi1pro.py --verify 10000         # 用独立算法对拍前 1 万位
python pi1pro.py "随便问什么"            # 输入被忽略，输出同一个流
```

安装加速器（可选）：

```bash
python -m pip install gmpy2
```

## 实测（Intel 20 核，单线程）

| 位数 | 用时 | 速度 |
|---|---|---|
| 10,000 | 0.01 s | — |
| 1,000,000 | 0.9 s | ~650k 位/秒 |
| 5,000,000 | 7.7 s | ~650k 位/秒 |
| 10,000,000 | 22.0 s | ~454k 位/秒 |

纯 Python（无 gmpy2）约为上述速度的 1/20：100 万位约 10 秒。

30 秒持续输出实测：**5,120,000 位**，全量校验与独立重算逐位一致。

## 正确性

| 校验 | 结果 |
|---|---|
| Chudnovsky vs Gibbons spigot（独立算法） | 前 10,000 位一致 |
| Chudnovsky vs Gauss–Legendre AGM（第三套算法） | 前 20,000 位一致 |
| 30 秒流式输出（5,120,000 位） | 与完整重算逐位一致 |
| 跨块前缀校验 | 每次重算都断言以旧前缀开头 |

## 速度说明

- 时间随位数超线性增长（大整数乘法本身如此），所以「无限」意味着
  「直到内存或你的耐心耗尽」，而不是恒定速度。
- 块倍增时输出会暂停数秒（1000 万位约 20 秒），进度打在 stderr。
- 输出是纯 ASCII 数字流，可直接管道给 `wc -c`、`head -c` 等命令。
