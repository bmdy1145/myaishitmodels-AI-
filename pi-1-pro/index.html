π-1-Pro

无限圆周率流 · 每一位都是真算出来的 · 纯 Python（可选 gmpy2 加速）

输入任意内容后，计算圆周率并持续输出，不限制大小，不打断就一直输出。

下载 pi-1m.txt（100 万位） README 源码

为什么不是神经网络

Transformer 无法无限生成 π 的数字而不漂移成胡编乱造。需求要的是「算多快就多快、 数字必须正确」，所以 π-1-Pro 用算法而不是权重：Chudnovsky 级数 + 二分拆分 + 整数平方根，并用独立的 Gibbons spigot 与 Gauss–Legendre AGM 交叉校验。

实测

1,000,000 位0.9 s（~650k 位/秒，gmpy2）
5,000,000 位7.7 s
10,000,000 位22.0 s
30 秒持续输出5,120,000 位，全量逐位校验通过
纯 Python（无 gmpy2）约为 1/20 速度，100 万位约 10 s

正确性

Chudnovsky vs Gibbons spigot前 10,000 位一致
Chudnovsky vs Gauss–Legendre AGM前 20,000 位一致
跨块校验每次重算都断言以已输出前缀开头

使用

cd core
python pi1pro.py                        # 无限输出（Ctrl-C 停止）
python pi1pro.py --max-digits 1000000   # 算到 100 万位
python pi1pro.py --out pi.txt           # 写文件
python pi1pro.py --verify 10000         # 用独立算法对拍
python -m pip install gmpy2             # 可选：20x 加速
时间随位数超线性增长（大整数乘法本身如此）。「无限」意味着 「直到内存或你的耐心耗尽」；块倍增时输出会暂停数秒，进度打在 stderr。
输出是纯 ASCII 数字流：python pi1pro.py | wc -c、 head -c 1000 都能直接用。
