parrot-80k

固定单句回复的 80 KB 迷你大模型 · 纯 NumPy · 零依赖

无论输入什么，都只回一句 听君一席话，如听一席话。

下载 parrot-mini.bin README content.txt

规格

模型文件81,972 bytes（80.1 KB）
参数74,880
结构2 层 / 4 头 / d_model 64 / d_ff 160 / RoPE / 用户窗口 64
量化int8 行量化 + float32 RMSNorm gamma + SHA-256 校验
训练200 步内收敛 / 36 s
自测1000 个差异极大的输入，答案 logits 逐位一致，min margin 6.68
单句生成11.6 ms（无 KV cache 的保守实现）
批量吞吐20 线程 batch 2048 约 185k 位置/s

原理

序列布局固定：[BOS] + 用户窗口(64 槽) + [SEP] + 答案 + [EOS]。 SEP 与答案位置的注意力掩码看不到任何用户槽位，位置 ID 也与输入长度无关， 因此任意输入的答案 logits 逐位相同（np.array_equal 断言）。 这是架构保证，不是概率碰巧；训练时用户槽位对答案损失的梯度严格为 0。

使用

# 下载 parrot-mini.bin 到本目录后
cd core
python chat.py --model ../parrot-80k/parrot-mini.bin --once "随便问"
printf '你好\n/exit\n' | python chat.py --model ../parrot-80k/parrot-mini.bin --no-delay
python parrot.py --model ../parrot-80k/parrot-mini.bin --selftest --n 1000
代码调用：import parrot; parrot.greet("随便问什么")。 换内容只需编辑 content.txt 后重跑 train.py --preset mini（约 36 s）。
